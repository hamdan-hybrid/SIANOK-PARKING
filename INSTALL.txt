SIANOK PARKING 1.1.0 (20261026)

Kebutuhan: Linux x64, Node.js 26 (v26.12.1 atau lebih baru), MariaDB 10.6+ (atau MySQL 8), ffmpeg (foto kamera gate).

1. Ekstrak paket:      tar -xzf sianok-parking-1.1.0-20261026.tar.gz && cd sianok-parking
2. Pasang otomatis:    sudo bash setup.sh   (Ubuntu Server 22.04 / 24.04: Node.js, PM2, MariaDB, FFmpeg, database,
                       .env, startup saat boot, health check). Panduan lengkap & pemulihan: INSTALL.md

Cara lama (tanpa setup.sh):
   Jalankan:           npm start            (kode instalasi tampil di terminal)
   Instalasi:          buka http://<ip-server>:3003 , isi kode instalasi yang tampil di terminal / log
                       (pm2 logs), koneksi database (host, user, password, nama database) dan pengaturan server.
                       Database dibuat, database.sql diimpor, dan .env ditulis otomatis.
                       Bila PM2 terpasang, aplikasi otomatis dipindah ke PM2 (cluster, restart otomatis bila error).
   Nyala saat boot:     pm2 startup          (jalankan perintah sudo yang ditampilkan, sekali saja)
   Perintah lain:       npm run pm2:logs  |  npm run pm2:restart  |  npm run pm2 (jalankan di PM2 bila belum)
Login awal:            admin / admin123 (segera ganti password).

User database harus boleh membuat database bila database belum ada.
Tabel tambahan dibuat otomatis saat server pertama kali jalan.
Detail operasional: OPERATIONS.md. API perangkat gate: GATE-API.md.
